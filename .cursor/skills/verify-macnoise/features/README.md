# MacNoise feature map

Use the built binary and isolated paths described in the parent skill. Each journey records its command, output, exit status, and observable result. Real macOS behavior requires a macOS host. Do not treat Windows results as macOS telemetry proof.

- [Discovery](discovery.md): list, categories, and module details.
- [Preview](preview.md): dry-run a module or scenario.
- [Run a module](run.md): exercise an explicit local TCP target.
- [Scenarios](scenario.md): run a connected file flow with isolated paths.
- [Output](output.md): inspect JSONL and audit records.
